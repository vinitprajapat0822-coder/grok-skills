# Set YouTube Studio Default Visibility to Unlisted

**Category**: YouTube Workflow  
**Source**: Video v-0zv2L9N0I  
**Why**: Prevents accidental public upload before processing finishes.

## Steps
1. Open YouTube Studio
2. Go to **Settings** (bottom left)
3. Click **Upload defaults**
4. Under **Basic info** → set **Visibility** to **Unlisted**
5. Save

## Result
Every new upload starts as Unlisted. You finish metadata + wait for HD processing, then manually switch to Public.
