# Blocked Words for Comment Moderation

**Category**: YouTube Community / Retention Protection  
**Source**: Video v-0zv2L9N0I  
**Goal**: Automatically hide comments that kill watch time (top negative comments make new viewers leave).

## Steps
1. YouTube Studio → **Settings**
2. **Community** → **Moderation**
3. Scroll to **Blocked words**
4. Add words (comma separated):

```
waste of time, fake, scam, unsubscribe, clickbait, boring, garbage, trash, don’t watch, dont watch, skip this
```

5. Save

## Extra Tips
- You can still approve or reply to held comments later.
- Review the held comments queue occasionally so real criticism is not completely silenced.
- Update the list based on actual toxic patterns you see.
